# 小型0050期貨（SRF）槓桿回測

`src/lib/futures.ts` 裡的 `LEVERAGE_CALIBRATION`、`HISTORICAL_CRASHES`、`CALIBRATED_PLAN`
三組常數是這裡跑出來的。改那些數字之前先在這裡重跑一次，不要憑感覺調。

## 怎麼跑

```bash
node prep.cjs          # 抓 Yahoo 日線並組出合成期貨價格序列 → series.json
node boot.cjs 400      # 區塊自助抽樣 → LEVERAGE_CALIBRATION 的來源（K 表）
node boot2.cjs 400     # 加碼階梯與獲利減碼階梯的抽樣比較（L、M 表）
node final.cjs         # 槓桿↔風險指標↔追繳/斷頭價、歷史崩盤對照（O、P 表）
node final2.cjs        # 對照「直接抱 0050」的基準線與轉倉成本臨界值（S、T、U 表）
node run2.cjs          # 分期表現、滾動 10 年視窗、成本與再平衡帶寬敏感度（B–E 表）
```

`prep.cjs` 會把抓下來的原始檔快取在本目錄；要強制重抓設 `REFETCH=1`。
`series.json`、`y0050.json`、`ytwii.json` 都是衍生檔，不進版控。

## 序列是怎麼組出來的

小型0050期貨很新，2000 年沒有這個商品，0050 本身也要到 2003 年才上市，
所以「2000 年到現在」只能用合成序列回答。做法：

* **2009-01 之後**：0050 還原權息收盤價（Yahoo）。這份資料**沒有回溯調整 2014-01 的
  1:4 分割**，`prep.cjs` 會自動偵測並修正——不修的話那天會多出一個 −75% 的假崩盤。
* **2000-01～2009-01**：用加權指數代理。波動用重疊期實測 beta（1.00，相關 0.83）校正，
  配息用 3.0%/年 補上，**不外加 alpha**——不把 2009 年後台積電的後見之明搬回過去。
* 再逐日扣掉台灣短期利率，把「現貨總報酬」變成「期貨超額報酬」。
  股票期貨的標準結果是 F = S·e^((r−q)T)：配息由基差吸收，多單不領息但也不付息，
  淨效果就是比現貨少賺一個無風險利率。這也是為什麼「用期貨做 1 倍」永遠虧成本。

## 模擬做了什麼

逐日洗價、**用當日最低價**檢查盤中風險指標（＜25% × 原始保證金就代沖銷）、
權益數低於維持保證金就追繳補錢、補不足就砍倉、轉倉成本、帶狀再平衡。

保證金用「佔契約價值的百分比」（原始 7.55%、維持 5.83%，取自現行 7,900／6,100 與現價）
而不是固定元數——期交所會隨標的價位調整級距，拿今天的 7,900 元去套 2000 年（合成價 12 元）
會算出完全不同的風險。

## 兩種讀法，回答不同問題

| | 歷史單一路徑 | 區塊自助抽樣 |
|---|---|---|
| 回答 | 那 26 年實際會怎樣 | 換一段歷史還成不成立 |
| 缺點 | 被「剛好從 2000 年泡沫頂點起算」綁架；結尾那段大多頭讓高槓桿看起來很聰明 | 打散了長期均值回歸，對「逢低加碼」不利 |

`LEVERAGE_CALIBRATION` 取自後者，因為做部位大小要看尾端風險，不是看中位數。
抽樣結果有 ±0.3pp 等級的蒙地卡羅雜訊，重跑不會逐位相同。
